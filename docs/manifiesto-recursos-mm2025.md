## 10. Criterios de deduplicación y descarte

- SHA-256 confirmó que no existen duplicados binarios exactos entre los 70 archivos.
- OTF y TTF no se trataron como duplicados exactos; son variantes de distribución relacionadas.
- La versión OTF de Gopher fue elegida como canónica para el micrositio por consistencia con el archivo de guía.
- Los PDF no fueron copiados a `assets/`: se conservaron como fuente temporal y se generaron derivados web únicamente para las piezas integradas.
- No se copiaron ocho paraderos ni 28 fuentes que no son necesarias en esta primera integración.
- No se eliminaron recursos originales.
